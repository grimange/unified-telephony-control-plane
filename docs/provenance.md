# Provenance

UTCP is an original repository for a vendor-neutral telephony control plane.

Do not copy code, schemas, prompts, documentation, fixtures, names, configuration, secrets, customer data, private hostnames, real telephone identities, or implementation details from APNTalk or any employer/client repository.

Allowed sources for this repository:

- Original work created for UTCP.
- Public documentation and standards used as references, cited where appropriate.
- Open-source dependencies introduced by later phases through their normal package managers and licenses.
- Synthetic examples and placeholder values that do not identify real systems or users.

All evidence committed to this repository must be concise and sanitized.
